# VB51 Report Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a separate Excel export for the VB51 unit report that matches `vb51.xlsx`.

**Architecture:** Reuse the existing reports module. Backend will aggregate customers by the same special units used by the account report, apply hardcoded VB51 plan targets from the sample workbook, and export a Times New Roman Excel workbook. Frontend will add one API method and one export button.

**Tech Stack:** TypeScript, Express, Drizzle ORM, ExcelJS, React, TanStack Query, Vitest.
